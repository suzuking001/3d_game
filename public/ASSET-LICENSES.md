## Armored warrior

`models/warrior.glb` is adapted from **Knight (Rigged - Mid Poly)** by **crownjoshua**.
Source: https://opengameart.org/content/knight-rigged-mid-poly
Original file: https://opengameart.org/sites/default/files/Knight_0.blend
License: **CC0 1.0** — https://creativecommons.org/publicdomain/zero/1.0/

Changes: reduced runtime skeleton (23 bones), simplified facial/finger weights,
new Idle/Run/Boost/Ascend/Fall animation clips, weathered PBR materials and a compact jet pack.
The original file is preserved in `art-source/warrior/`. Animations are authored by this project;
the original asset did not contain locomotion clips. Embedded Blender scripts are never executed.

World geometry, jet housings, soot masks and particle masks are generated by this project.
Game screenshots in `docs/references/` are publisher-owned visual references.
They are not runtime assets and are not included in the production build.
